# LuminaCore

Research project for a hybrid neuromorphic photonic Edge AI accelerator.

## Scope
- Photonic integrated circuits: MZI meshes, MRR and WDM
- Nonlinear optical activation research: VO2 on SiN/BTO waveguides
- Numerical simulation and hardware-aware neural network compilation
- PIC/FPGA integration, characterization and reproducible benchmarking

## Project status
**Research specification / repository initialization.** No fabricated chip, verified energy/latency advantage, tape-out or hardware prototype is claimed.

See [ROADMAP.md](ROADMAP.md) for milestones and evidence gates and [docs/RESEARCH_ASSUMPTIONS.md](docs/RESEARCH_ASSUMPTIONS.md) for claims requiring validation.
